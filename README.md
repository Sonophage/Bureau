# Bureau

A dark theme for [Obsidian](https://obsidian.md), inspired by the austere institutional aesthetic of the Federal Bureau of Control.

![screenshot](screenshot.png)

## Installation

### Manual

1. Download `theme.css` and `manifest.json`.
2. Copy them into your vault at `.obsidian/themes/Bureau/`.
3. In Obsidian: **Settings → Appearance → Themes** and select **Bureau**.

## Development

The theme is a single `theme.css` file. Edit it directly and reload Obsidian
(or use a hot-reload plugin) to see changes.
